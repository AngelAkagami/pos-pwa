Falta la configuración de Supabase

La aplicación todavía no tiene credenciales para conectar con la base de datos compartida. No se está simulando la sincronización: hasta configurarla, el tablero no carga datos.

  1. Crea un proyecto en supabase.com.
  2. En SQL Editor, ejecuta supabase/schema.sql y luego supabase/seed.sql.
  3. Copia js/config.example.js a js/config.js y pega la Project URL y la clave anon/public.
  4. Recarga esta página.

Consulta el README.md para el procedimiento completo.

    Rutina XP de cada iteración

    • 1. Planificación

      El equipo define el alcance de la semana, las historias y los criterios de aceptación.

    • 2. Programación en parejas

      Rotación de roles driver/navigator: quien escribe guía, quien observa revisa en tiempo real.

    • 3. Integración y pruebas continuas

      Integración frecuente y automatizada. Marcar un checkbox registra avance; no equivale a pasar las pruebas de aceptación.

    • 4. Demo + retrospectiva

      Al cierre de cada iteración se muestra lo terminado y se acuerdan los cambios para la siguiente semana.
